# C - Structures, typedef

This directory contains C exercises about structures and `typedef`.

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o a

## Files

| File | Description |
|------|-------------|
| `dog.h` | Header file defining `struct dog`, `dog_t` and prototypes |
| `1-init_dog.c` | Initializes a variable of type struct dog |
| `2-print_dog.c` | Prints a struct dog |
| `4-new_dog.c` | Creates a new dog (copies name and owner) |
| `5-free_dog.c` | Frees a dog |
