# C - Dynamic memory allocation (malloc, free)

This directory contains C exercises about dynamic memory allocation
using `malloc` and `free`.

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o a

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with function prototypes |
| `0-create_array.c` | Creates an array of chars and initializes it with a specific char |
| `1-strdup.c` | Returns a pointer to a newly allocated copy of a string |
| `2-str_concat.c` | Concatenates two strings |
| `3-alloc_grid.c` | Returns a 2D array of integers initialized to 0 |
| `4-free_grid.c` | Frees a 2D grid created by alloc_grid |
