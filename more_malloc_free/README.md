# C - More malloc, free

This directory contains C exercises about dynamic memory allocation
using `malloc` and `free`.

## Compilation

    gcc -Wall -pedantic -Werror -Wextra -std=gnu89 *.c -o a

## Files

| File | Description |
|------|-------------|
| `main.h` | Header file with function prototypes |
| `0-malloc_checked.c` | Allocates memory using malloc, exits with status 98 on failure |
| `1-string_nconcat.c` | Concatenates s1 with the first n bytes of s2 |
| `2-calloc.c` | Allocates zeroed memory for an array using malloc |
| `3-array_range.c` | Creates an array of integers from min to max |
